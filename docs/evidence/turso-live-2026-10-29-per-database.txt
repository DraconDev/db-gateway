## What this means for the comparison

PARITY where it matters:
- Branch now / branch from a point in time. `dg branch create <parent> <name>`
  and `dg branch create --from <ISO8601>` are the same two operations, and `dg`
  reports the backup window when the moment falls outside it.
- Per-database "Export Database → Download SQLite File" is `dg export --out`.
- Per-database columns visible in the list (rows read/written, storage) are what
  `dg inspect` / `dg list` / `dg contents` answer.

GENUINE GAPS, in operator terms:
1. Remote access control is entirely absent from `dg`. Block Reads, Block
   Writes, Allow ATTACH, Delete Protection and the CIDR/VPC allow-list have no
   `dg` counterpart at all — `dg` listens on loopback only and reaches remote
   gateways through an SSH tunnel, so per-database network admission is not part
   of its model. (The nearest thing is the credential's database scope and role,
   which is authorization, not network admission.)
2. TIME SERIES history is absent. Every chart here is a 30-day series; `dg
   status`/`dg watch` are present-tense counters that reset on restart.
3. Token invalidation as a bulk action: Turso has "Invalidate All Tokens" for a
   database. `dg` revokes credentials one at a time by name (`dg key revoke`),
   and there is no "revoke every key scoped to database X" verb.

## Per-database Top Queries page

"Top Queries — Ranked by rows read · Today (UTC)", with a "Rank by" selector, a
"Show totals" toggle and a Today / This month range. Each entry: Query time
(avg), Rows read (avg), Rows written (avg), Queries, then the statement text.

Read live for dracon-music-dev, first two entries:
  - 393 µs avg, 85 rows read avg, 0 written, 1 query:
      SELECT m.tbl_name as "table", m.sql as "tableSql", im.sql as "indexSql",
      il.name as "name", ii.name as "column", il.[unique] as "isUnique",
      il.origin, il.seq, ii.cid, ii.seqno
      FROM sqlite_master AS m, pragma_index_list(m.name) AS il,
           pragma_index_info(il.name) AS ii
      LEFT JOIN sqlite_master AS im ON im.type = 'index' AND im.name = il.name
      WHERE m.type = 'table' and m.tbl_name != '_cf_KV'
      ORDER BY m.name COLLATE NOCASE;
  - 7.61 ms avg, then further entries

Note that the FIRST entry is Drizzle Studio's own introspection query, not the
application's workload: the console's Edit Data page runs schema queries against
the database to draw its grid, and those appear in the same Top Queries list.
`dg` has no equivalent self-instrumentation of the console, but it does mean the
two tools' "top query" lists are not measuring the same population — Turso's
includes the dashboard's own reads, `dg queries` includes only API traffic.

## Gap correction for the token-invalidation row above

Verified against the CLI: `dg key revoke --help` takes exactly one positional
`<NAME>`, and `src/api.rs::revoke` handles one credential. So "Invalidate All
Tokens" for a database is a real gap, not a wording difference — there is no
database-scoped bulk revoke.
