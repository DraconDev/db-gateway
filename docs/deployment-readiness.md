# Deployment readiness

This gateway is in pre-production development. It is not ready for
production use or production data.

Setup is generic: run the service on a Linux host with persistent local
storage, configure a private transport (SSH tunnel or equivalent) and
scoped keys, and see `docs/deployment.md` for the generic deploy
procedure. This checklist intentionally contains no host specs, measured
resource numbers, or dated verification verdicts.
