## Verdict

The **core is in unusually good shape for a personal project**: bounded
SQLite execution, authorizer-based read-only/scoped-key enforcement,
generation-bound credentials, idempotent writes with lost-ack discipline,
safe lifecycle (clone/export/import/tombstone-purge), backup freshness +
digest watchdog, and a large, green, adversarial test suite. No TODO/FIXME
debt in `src/`; exactly one `unsafe` block (`libc::kill` in
`src/main.rs:426`, companion shutdown).

The risk has moved **outside the core**: status documents contradict each
other and the newer evidence, the off-host backup story has a silent
coverage gap for new databases, one production unit exists only on the
host (not in the repo), and the Turso migration — the project's stated
purpose — is still blocked on unverified remote facts and a missing Rust
client path. Nothing below requires weakening any existing contract.

  sound; several past incidents (see watchdog/litestream transcripts)
